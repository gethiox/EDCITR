# Contributing to EDCITR

First off, thank you for considering contributing to EDCITR! Community contributions are incredibly valuable.

### The Contributor License Agreement (CLA)
To ensure the project remains legally sound and to allow the maintainer to manage the project's future effectively,
we require all contributors to sign a Contributor License Agreement.

When you open your first Pull Request, a bot will automatically prompt you to review and sign the CLA.

You can read the full text of the CLA with link **[HERE](https://gist.github.com/gethiox/1bee88672f7157e9d5d2edf23c20f94e)**

**Pull Requests cannot be merged until the CLA is signed.**

### How to Contribute
1. **Open a Pull Request** against the `main` branch of this repository.
2. **Hope for the best**, eventually your request will be accepted or rejected by the repository owner.

### Reporting Bugs and Requesting Features
If you aren't writing code but want to report a bug or request a feature, please use the GitHub Issues tab. Be sure to provide as much context as possible, including application logs if relevant!
